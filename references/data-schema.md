# 数据 Schema（古籍共读生成器）

构建脚本 `scripts/build_reader.py` 读取项目目录下的 `config.json` 与若干数据文件，渲染 `assets/reader-template.html` 为单文件 `index.html`。**所有数据文件都是可选的，至少要有 `chapters.json`。**

构建命令：
```
python3 scripts/build_reader.py 项目目录 [--out dist/index.html]
```

---

## config.json（必需）

| 字段 | 说明 |
|------|------|
| `book` | 书名，如「中庸」。会出现在标题、品牌字、页眉等所有结构性位置。 |
| `key` | localStorage 键前缀（仅小写字母数字）。默认取 book 的拼音/英文。用于 `进度`/`书签`/`笔记` 存储隔离。 |
| `favchar` | 浏览器页签 favicon 用的字，默认取 `book[0]`。印章红圆角 + 白字。 |
| `theme` | 主题色（顶栏/印章/强调），默认 `#a02c2c`。 |
| `subtitle` | 封面标题下方一行说明，**必须有且须准确**。格式如「《礼记》第四十二篇 · 曾子述 · 四书之首」。写错作者归因是硬伤。 |
| `share_base` | 分享链接基址。留空 `''` 时自动用 `location.origin`。若部署在子路径需显式填。 |
| `schools` | 解读标签的学派/视角简介字典 `{标签: 简介}`。jiedu 中出现该标签即展开简介。 |
| `basis` | 解读标签的「所本」字典（可选），如 `{"程朱理学":"《四书章句集注》"}`。 |
| `segments` | 章间呼应徽标分段 `[[阈值, 标签], ...]`，如 `[[1,"三纲领"],[5,"八条目"],[11,"平天下"]]`；留空无徽标。 |
| `intro` | 封面引言段落（HTML 允许）。 |
| `sidebar_foot` | 侧栏底部说明（HTML 允许）。 |

## chapters.json（必需）

```json
[
  {"n": 1, "label": "天命之谓性", "text": "天命之谓性，率性之谓道……"},
  {"n": 2, "label": "君子中庸", "text": "仲尼曰……"}
]
```
- `n`：章号（1..N，连续）。
- `label`：章名，用于目录与分享标题。
- `text`：原文。若需按义理分段（长章），可加 `"paras": ["段1","段2"]`，否则整段显示。
- 全书按「一天一章」自动排程：开始日期 + 第 n 天 = 该章。

---

## sentences.json（可选 · 逐句译文）

```json
{
  "1": [["原文句", "今译句"], ["原文句2", "今译句2"]],
  "2": [["……", "……"]]
}
```
键为章号字符串。驱动「译文」标签的 原文｜今译 对照。缺失章 → 该标签不显示。

---

## content.json（可选 · 章内详解）

```json
{
  "1": {
    "zhu": [["字词", "注释"], ["字词2", "注释2"]],
    "chuan": "串讲段落，可含\n换行分段。",
    "jingzheng": [["《书名》", "引文", "互见说明"], ["……", "……", "……"]],
    "jiedu": [
      {"label": "程朱理学", "text": "解读文字", "intro": "可选覆盖schools简介", "basis": "可选覆盖basis"},
      {"label": "生活启发", "text": "……"}
    ],
    "dao": "导读文字。",
    "sheng": ["可选：此章省察问1", "省察问2"]
  }
}
```
- `zhu` → 注释标签；`chuan`/`jingzheng` → 串讲标签（经证链，以经解经）。
- `jiedu` → 解读标签（四视角）。每个分项含 `label`（如"程朱理学"）、`text`（正文），可选 `intro`（覆盖 schools 简介）、`basis`（覆盖 config.basis）。
- `dao` → 导读标签。
- `sheng` → 省察问（也可放 p1.reflections，二者任一存在即显示）。
- **格式约束**：`content` 必须是 dict（key 为章号字符串 `"1"`），**不能是 list**。标签按「有内容才显示」动态生成。

## study.json（可选 · 研读专区）

```json
{
  "structure": [["一、总纲", "第1章", "说明文字", "重点：xxx"], ...],
  "concepts": [["概念", "拼音", "定义", "1,2,3", [["1","出处句"],["2","出处句"]]], ...],
  "quotes":   [["名句", "章号数字", "语境说明(可选)"], ...],
  "spine":    [["分段名", "第X–Y章", "说明"], ...],
  "anshen":   ["安心签1", "安心签2", ...],          // 长度=章数，封面每日抽一条
  "modern_anxiety": [{"theme":"焦虑主题","stress":"现代处境","remedy":"经典对症","quote":"引文"}],
  "cite":     "引用与出处说明文字（可选，默认有通用版）"
}
```
- **格式约束**：`structure`/`spine` 为 list of lists，**不可写成字符串**。
- `concepts` 第 5 项（occurrences）必须填真实引文句子，**不可用数字占位**。
- `modern_anxiety` 字段名严格为 `theme`/`stress`/`remedy`/`quote`，**不可用 `title`/`problem`/`cure`**。
- 研读页固定 10 个版块，有数据才渲染对应版块。

## p1.json（可选 · 参考/人物/省察/呼应）

```json
{
  "bibliography": [["书名", "说明"], ...],
  "figures":      [["人名", "身份", "小传"], ...],
  "reflections":  {"1": ["省察问1","省察问2"], "2": ["……"]},   // 驱动「省察」标签
  "echoes":       [["章号", "要旨", "呼应章号逗号分隔", "说明"], ...]
}
```

## p2.json（可选 · 朱注/互参/专题）

```json
{
  "zhuzhu": {"1": "朱子此章所注……", "2": "……"},     // 驱动「朱注」标签
  "sishu":  [{"zh":"第一章","theme":"主题","chaps":[1,2],
             "refs":[{"book":"《大学》","passage":"……","note":"……"}]}],
  "topics": [{"name":"专题名","desc":"说明","passages":[["章号","句","注"]]}]
}
```

## pinyin.json（强烈建议 · 注音/通假词典）

```json
{
  "PINYIN":   {"罟":"gǔ", "擭":"huò"},
  "TONGGJIA": {"期":"读 jī，一整月（期月）"},
  "PHRASE":   {"于穆": ["wū", "读 wū，叹词，深远肃穆貌"]}
}
```
- `PINYIN`：生僻/特殊读音字 → 拼音（ruby 注音）。
- `TONGGJIA`：通假/异读字 → 虚线下划线 + 点按说明。
- `PHRASE`：两字短语（如古典叹词「于穆」读 wū）→ 短语级注音。
- 缺失则该字不注音（保持版面干净）。

## 输出契约

构建后 `index.html` 内含（运行时 JS 变量）：
`CHAPTERS`(章数据) `TOTAL`(章数) `CN`(中文数字数组) `ANSHEN`(安心签) `SHENGQ`(省察问) `LS_KEY`/`LAST_KEY`/`SHENG_KEY`(进度/书签/笔记键) `PAGED`(默认分页) `SHARE_BASE`(分享基址)。

功能：单文件翻页阅读、左目录 scroll-spy、开始日期自动定位「今日共读」、每章/每日分享直达链接、阅读书签（仅本机）、注音开关、工具箱（设置/笔记/分享）、研读专区、安心签、省察笔记。
