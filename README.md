# 古籍共读网站生成器

> 一个 WorkBuddy Skill：把任意公有领域古籍做成**单文件、手机优先、零登录零后端**的在线共读网站。用户只需说一句话。

## 这是什么

一个可复用的古籍共读网站生成器，封装为 WorkBuddy 开放平台的 Skill。核心理念：**一天一章、群内共读、双击即开**。

AI 收到「帮我做一个《书名》的在线共读网站」后，自动上网查找公有领域底本、整理数据、构建出自包含的单文件 `index.html`——无外部依赖、无账号登录、无云端，双击即可在浏览器打开，也能托管到任意静态空间。

**线上示例**：[《中庸》33 天共读站](https://zhongyong.aiyazone.com) 即由本 Skill 生成。

## 核心体验

| 模块 | 说明 |
|---|---|
| 一天一章 | 设置开始日期后自动排程，封面「继续阅读」一键跳上次读到章 |
| 分页 / 连续 | 一章一页翻读（键盘翻页）或传统长页，自由切换 |
| 左侧目录 | 随阅读自动高亮定位（scroll-spy），窄屏折叠为抽屉 |
| 每章七标签 | 译文（逐句对照）、注释（注音 + 通假点击提示）、串讲、四视角解读、导读、省察（自省笔记）、朱注 |
| 分享本章 | 生成直达该章的链接，适合在微信群分发 |
| 研读专区 | 结构脉络 / 核心概念词典 / 名句摘录 / 当代焦虑 / 以经解经 / 参考书目 / 人物小传 / 章间呼应 / 四书互参 |
| 每日安心签 | 封面独立卡片，每天一句与当日章节呼应的安心之语 |
| 工具箱 | 阅读设置（注音 / 模式）/ 共读设置（开始日期）/ 践行笔记（本机保存、可导出）/ 安心签 |
| 技术特性 | 单文件自包含 · 手机优先 · 零登录零后端 · 不依赖任何外部资源 |

## 使用方式

### 普通用户（在 WorkBuddy 中使用）

在 WorkBuddy 里说一句话即可：

> 「帮我做一个《大学》的在线共读网站。」

底本数据、译文、注释、研读资料——全部由 AI 上网搜集并整理，用户无需准备任何素材。

### 安装 Skill

1. 在 WorkBuddy 开放平台搜索「古籍共读网站生成器」
2. 安装后，在对话中直接描述要做的书即可

### 本地开发

```bash
# 构建示例（《中庸》3 章最小可运行版）
python3 scripts/build_reader.py samples --out samples/index.html

# 浏览器直接打开
open samples/index.html
```

## 可生成的书籍类型

本 Skill 适用于**公有领域**古籍 / 经典文本：

- 《四书》系列：大学、中庸、论语、孟子（可启用朱注与四书互参）
- 道家经典：道德经、庄子
- 兵家 / 法家 / 杂家：孙子兵法、止学、素书
- 其它可公开获取底本的经典文本

> 版权说明：Skill 仅收录公有领域古籍原文（维基文库 / 国学网等可作底本）。疏通、译文、解读、省察等内容由 AI 自撰或注明出处，不复制现代出版物受保护内容。
